# CineBook - Movie Booking Website (MERN)

1. Start MongoDB (local service) or put an Atlas URL in server/.env as MONGO_URI
2. Server:  cd server && npm install && npm run dev      (http://localhost:5000)
3. Client:  cd client && npm install && npm run dev      (http://localhost:5173)
4. Admin: open /admin/register, use the ADMIN_CODE from server/.env (default admin123)
